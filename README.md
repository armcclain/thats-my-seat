# That's My Seat — release notes (v2)

## What's in this folder
- `index.html` — the whole app in one self-contained file (open it, or serve it from GitHub Pages).
- `backend/AppsScript.gs` — Google Sheets sync backend.
- `icons/icons` - pngs for app bookmark icon



## What is this
Have you ever wanted to know if you've sat in the same metro seat twice? Now you can. Log your rides, pick your seat, and see if your friends have sat their too. There's a lot of seats, but it's a small world. Why not see what happens!
